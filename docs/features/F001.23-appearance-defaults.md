# F001.23 — Udseende i brugermenuen: Lag som standard, Neuroner kun hvor appen beder om det, paletten som dropdown

Ejerens ordre 10/10 (via appkit #2577, appkit-F001.10):
1. «Neuroner skal tages ud af den gængse Appkit skabelon, den er reelt set kun til trail og cardmem»
2. «Lag skal altid være default»
3. «Paletten er ikke pæn» (4 Segmented-knapper der ombrydes)

## Målt i koden før planen
- Neuron-lærredet tegnes kun af apps der selv kalder `mountConstellation` (theme/src/constellation.ts). app-shell viser blot vælgeren. Så «ud af skabelonen» = (a) vælgeren bliver opt-in i app-shell, (b) appkits starter kalder ikke mountConstellation. theme's backdrop-standard (neurons) bliver stående, fordi den kun betyder noget i apps der tegner lærredet — og dem (trail, cardmem) skal have neuroner som standard.
- **Fælden ved Lag-standarden:** i dag gemmes `flat` som et SLETTET nøgle (theme/src/palette.ts, «the default is no attribute»). En bruger der aktivt valgte Flad, kan ikke skelnes fra en der aldrig valgte. Skiftes standarden, får også de Lag én gang. Det er uundgåeligt for eksisterende valg og følger af ordren; fremover gemmes `flat` eksplicit, så et nyt valg holder.

## Ændringer
- **theme** (minor): `surfaces` standard `layered`. `initPalette`: gemt `flat` → flat, ellers layered. `setSurfaces('flat')` gemmer `"flat"`; attributten `data-surfaces` sættes til `layered` / fjernes for flat (CSS uændret). `prePaintScript`: sæt layered medmindre gemt === "flat".
- **app-shell** (minor): `UserMenuProps.appearance?: boolean | { backdrop?: boolean }`. Baggrund-rækken kun ved `{ backdrop: true }`. Palet: custom dropdown (listbox), piletaster/Enter/Escape, fokus tilbage, testid `user-menu-palette` + `user-menu-palette-<id>`, ingen native `<select>` (D-4cd764).

## Reuse
Discovery: kapaciteterne ejes af @broberg/theme og @broberg/app-shell selv. Dropdown-mønsteret genbruges fra app-shells eksisterende menu-tastaturhåndtering, hvis den passer; ellers en lille lokal komponent i preact.tsx — ingen ny pakke.

## Konsekvens for forbrugere
- trail og cardmem: tilføj `appearance: { backdrop: true }` for at beholde Baggrund-vælgeren.
- Brugere der tidligere valgte Flad, ser Lag én gang efter bump.
