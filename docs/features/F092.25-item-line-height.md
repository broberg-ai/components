# F092.25 — linjehøjde som token på sidebar-rækker

scout #2720 (11/10): ejeren vil have «samme afstand som i Claude Desktop». Målt i hans skærmbillede: rækker 40px top til top, tekst ca. 17px, 8px-ring med ~14px luft til teksten. Scouts værdier: font-size 17px, line-height 24px, padding 8px 12px, gap 14px.

## Problem
F092.24 (app-shell 0.16.0) gav tokens for skriftstørrelse, padding, gap, radius, ikonfarve og aktiv række, men ikke linjehøjde. Rækkens højde afhænger derfor af fontens normale linjehøjde og kan ikke sættes præcist.

## Ændring (app-shell, minor, additiv)
- `.bas-item { line-height: var(--bas-item-line-height); }` UDEN fallback. Er tokenet ikke sat, er deklarationen ugyldig ved beregning og opfører sig som `unset`, og da line-height arves, bliver resultatet det samme som i dag. Er det sat, bestemmer det linjehøjden.
- README: tokenet + Claude Desktop-eksemplet (17px / 24px / 8px 12px / 14px = 40px).
- Eksempel-appen: `?desktop` med scouts værdier.

## Reuse
Udvider F092.24's tokens i app-shell.
