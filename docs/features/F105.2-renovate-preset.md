# F105.2 — Renovate-preset for image-hygiejne

Se epicen `docs/features/F105-image-hygiene-engine.md`.

## Scope
- `renovate/image-hygiene.json`: `pinDigests` for dockerfile-manageren, PR-baserede opdateringer, `automerge` kun for `digest` og `vulnerabilityAlerts`, `automergeType: pr`, kræver grønne checks (Renovate merger ikke røde PR'er medmindre `ignoreTests`, som vi aldrig sætter), major aldrig automerge.
- Repoer bruger det med `"extends": ["github>broberg-ai/components//renovate/image-hygiene"]`.
- Valideret med `renovate-config-validator`.

## Afhængighed
Renovate-GitHub-appen skal være installeret på organisationen — en ejer-handling. Er den ikke det, dokumenteres det på kortet.

## Non-goals
Andre managers end Dockerfile/fly.toml-images.
