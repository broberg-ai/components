# F084.164 — «BrobergID» hedder nu «BID» i alle fælles pakker

## Motivation
Ejer-ordre 15/10 (Christian via broberg-id #3279, gentaget af ai-sdk #3287): «BrobergID» og «Broberg ID» hedder nu «BID» overalt hvor et menneske læser det — UI, knapper, mails, docs. Kodekommentarer må blive. Logotypen er «B» i tekstfarven + «ID» i terracotta (accent-text #ff6a45 mørk / #c93a16 lys).

## Målt i components 15/10
- `packages/app-shell/src/index.ts` — `bidSecurity`: «Sikkerhed i BrobergID» / «Security in BrobergID».
- `packages/web-clipper/src/ui.tsx` — login-knappen: «Log ind med BrobergID» / «Sign in with BrobergID».
- `packages/sso/src/{fetch-ticket,jwks,client,config}.ts` — fejlbeskeder/forklaringer med «BrobergID».
- `packages/secret-scan/src/index.ts` — regel-beskrivelse «BrobergID app key».
- `CLAUDE.md` Reuse-first-blokken — rettet i 01b4cd2; udrulning til alle repoer bedt om hos cardmem.

## Scope
Tekstændring i de nævnte strenge + tests der hævder den nye tekst. Logotype-styling i UI kun hvor pakken selv tegner navnet som mærke (ingen i dag — det er knaptekst og etiketter, som forbliver ren tekst).

## Non-goals
- Identifiers (`bidIssuer`, `createBidAuth`, env-navne) ændres ikke.
- Kommentarer og historiske plan-docs ændres ikke.

## Reuse
Ingen ny kapabilitet.

## Rollout
Patch-udgivelser af app-shell, web-clipper, sso, secret-scan; release-rapport til forbrugerne.
