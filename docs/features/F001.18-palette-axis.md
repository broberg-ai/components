# F001.18 — Palet-aksen i `@broberg/theme`

> Christian 3/10 2026, relayeret ensslydende af helpdesk (#1571, #1572) og trail (#1573): HelpDesk-konsollen, trail-appen og Cardmem skal have «de helt samme muligheder» for farvetema som Cardmem — «så de 3 store flagskibe i broberg.ai-flåden bliver ensartet».

## Kilden

Cardmem har det i dag, kun hos sig selv: `apps/web/src/design-tokens-palettes.css` + `lib/theme.ts` (origin/main 433e7e27). Tre akser:

| akse | attribut | værdier (id → label) |
|---|---|---|
| Theme | `data-theme` | light · dark (+ system som præference) |
| Palette | `data-palette` | classic (ingen attribut) → Ember · cool → Graphite · warm → Sandstone · broberg → Fjord |
| Surfaces | `data-surfaces` | flat (ingen attribut) · layered |

Id'erne er cardmems gemte værdier, ikke labels — en omdøbning må ikke nulstille nogens valg (helpdesk #1574, aftalt med trail).

Backdrop (neurons/plain) er app-grafik, ikke tokens, og bliver hos appen (aftalt med helpdesk og trail).

## Hvad pakken leverer

1. **`css/palettes.css`** — plain CSS (ingen `@theme`), så den kan `@import`es fra node_modules:
   - Klassisk base for det FÆLLES sæt: alle variabler en palet overskriver + status-familierne (clay, olive, amber, sky, danger, success) + graph-* + deres `var()`-lukning. 54 variabler, lys under `:root`, mørk under `:root[data-theme='dark']`. Værdier genereret fra cardmems filer, ikke skrevet af i hånden.
   - De tre paletter × lys/mørk, ordret.
   - Surfaces: defaults + layered for alle 8 kombinationer, ordret.
   - Cardmems app-specifikke tokens (`--acc-*`, `--booklet-*`, `--mk-*` …) er IKKE med — de bliver hos cardmem.
2. **JS** i den eksisterende store: `getPalette/setPalette/onPaletteChange`, `getSurfaces/setSurfaces/onSurfacesChange`, `PALETTES`, `PALETTE_LABELS`, med konfigurerbare localStorage-nøgler.
3. **`prePaintScript`** sætter også `data-palette` og `data-surfaces` før første maling.

Forbrugerne mapper selv deres navne oven på (`--color-bg: var(--bg)` i trail; helpdesk `--panel` osv.).

## Forhold til de eksisterende `light-cool`/`dark-warm`/`dark-broberg`-temaer

De bliver stående uændret (andre forbrugere bruger dem). Palet-aksen er et andet ordforråd (cardmems), og en app bruger ét af de to. README siger det.

## Tests (cardmems liste, #1576)

Porteret fra `apps/web/src/palettes.test.ts`, målt fra pakkens egen fil: kontrast pr. palet × tema, «every overridden token exists in the base», CONTROL-testen, layered-testene og flat-defaults. Plus en snapshot-test mod cardmems værdier og test af JS + pre-paint.

## Udrulning
