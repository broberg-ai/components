# F084.156 — Billetter læses fremtidssikkert

**Bestilt af:** broberg-id 10/10 2026 (#2559), deres broberg-id-F087.15 (agent-planen rev. 8). Bygges før DPoP-tjekket (F087.16).

## Målt i `src/ticket.ts` (0.14.2)
1. Kun `act.sub` læses. En kæde menneske → agent → underagent (RFC 8693 §4.1, indlejret `act.act`) forkortes lydløst til første led.
2. En `act` uden streng-`sub` bliver `act: null`, så kalderen ser ud til at handle på egne vegne. Samme fejlretning som 1.
3. `cnf` ignoreres. En DPoP-bundet billet godtages som bearer; bindingen beskytter intet, før F087.16 tjekker beviset.
4. Ingen `ver`.

## Løsning (alt additivt)
- `principal.version`: uden `ver` → 0, `ver:1` → 1, `ver` > 1 → afvist med navngivet fejl, så en fremtidig `ver:2` aldrig læses lydløst med `ver:1`-regler.
- `principal.act`: `{ sub, act? }` rekursivt. `act.sub` virker som før. Maks dybde 5; dybere afvises. Et led uden streng-`sub` afvises.
- `principal.cnf`: `{ jkt } | null`. Ingen afvisning; beviset er F087.16.

## Ejerskab
BID sætter `ver`. components bygger læsningen. Bevægelsen i begge ender prøves af BID's samspilstest (src/token-exchange.test.ts, F087.4) mod den udgivne version.
