# F099.11 — The popup keeps one height in every state

> Story under F099. Owner order 13/10.

## Motivation
Owner (via jam #3190): «Når man prøver skal dialogen ikke blive mindre, den skal hele tiden have samme højde — det er nemlig også lidt en fejl i dag både i jam og trail clippers. Fra det øjeblik man klikker på knappen skal den have max højde straks, og så sker alt det sjove inde i den samme højde.» Directly to components: «tag den faste popup-højde nu».

## Design
`.bwc-popup` gets a fixed `height: var(--bwc-popup-height, 420px)` with `overflow-y: auto`; the body flexes. The extension sets the number in its OWN CSS — the base only keeps it still. This follows the owner's direction the same day that design belongs to the site that owns the clipper (see the headless story F099.12 and the proposed decision).

## Reuse
Extends @broberg/web-clipper's existing stylesheet.

## Verification
Lens on examples/web-clipper preview: height identical before login, ready, clipping and result (420 px × 4); negative control on the previous build jumps.

## Rollout
Patch release (CSS only), report to jam + trail.
