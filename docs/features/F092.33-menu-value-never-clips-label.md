# F092.33 — ItemActionsMenu: a long value clips the value, never the label

scout #2830 (11/10, prod, Lens e3cea13d): with 0.22.0 a long `value` squeezes the label to nothing — «Sortér efter · Seneste aktivitet» renders as «Sor… Seneste aktivitet ›».

## Cause
`.bas-rowmenu__label` is `flex: 1` (basis 0, min-width 0) and the value is `flex: none`, so when space runs out the label is the only thing that can give.

## Fix
1. Label `flex: 1 1 auto` (basis = its content); value `flex: 0 1000 auto; min-width: 0` with ellipsis — the value shrinks first, the label only once the value is gone. A label without a value still ellipses when too long.
2. The menu sizes to its content: `min-width: var(--bas-menu-min-width, 240px)`, `max-width: min(var(--bas-menu-max-width, 320px), 100vw - 16px)`, no fixed width from JS. Positioning reads the measured width (falls back to 240 where layout reports 0).

Non-goals: keyboard model, placement rules.

## Reuse
This is the shared package itself (@broberg/app-shell).
