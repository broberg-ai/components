# F038.50 — Playbooks i Discovery

**Bestilt af:** sanneandersen #54504 (24/11 2026), på Christians ordre: «lav et nyt område Playbooks på discovery.broberg.ai».

## Hvorfor
sanneandersen brugte 2½ måned og ~15 rettelser på at komme fra destination charges til direct charges i Stripe Connect (Stripes gebyr blev trukket hos WebHouse: −4,60 kr pr. 700 kr-booking). FDAA skal i gang nu. En sådan opskrift hører ikke hjemme i én pakkes README eller som et infra-tip på én linje — den er en trin-for-trin-vejledning skrevet af den session der lærte den, og den skal kunne findes som alt andet i Discovery.

## Scope
- **Lager:** tabellen `playbooks` i Discoverys enroll-database (Turso): slug (PK), title, summary, kw (JSON), body (markdown), owner_session, repo, created_at, updated_at, revision.
- **Indmelding:** `POST /api/playbooks` med samme nøgle som enroll (`x-discovery-session` + `x-enroll-key`). Body `{slug, title, summary, kw[], body, repo?}`. Upsert; kun ejer-sessionen må opdatere sin slug. Grænser: slug `^[a-z0-9][a-z0-9-]{2,79}$`, title ≤ 160, summary ≤ 400, body ≤ 200 KB.
- **Læsning:** `GET /playbooks` (liste), `GET /playbooks/:slug` (side), `GET /api/playbooks`, `GET /api/playbooks/:slug` (metadata + rå markdown).
- **Fundbarhed:** `/api/search` får nøglen `playbooks`; `/llms.txt` og `/ai` lister titel + adresse; `/llms-full.txt` indeholder hele teksten.
- **Rendering:** en lille markdown-renderer i Discovery der ESCAPER alt først og derefter kun genkender overskrifter, lister, tabeller, kodeblokke, citater, `inline code`, **fed** og http(s)-links. Ingen rå HTML.

## Non-goals
- Gennemgang/godkendelse af en playbook før den vises: siden siger hvem der indmeldte den og hvornår. components ejer formen, ikke indholdet.
- Playbooks som filer i components-repoet (to kilder ville glide fra hinanden).
- Offentlig adgang: Discovery er lukket (D-81abe9).

## Arkitektur
```
repo-session ── POST /api/playbooks (session-nøgle) ──► Turso: playbooks
                                                        │
/playbooks · /playbooks/:slug · /api/playbooks · /api/search · /llms*.txt ◄┘
```

## Reuse
Discovery-søgning: Discovery selv (F038) og dens enroll-store (F039) — samme database, samme nøgle, ingen ny hemmelighed. Ingen markdown-pakke i @broberg/*-inventaret; en tredjeparts-renderer + sanitizer ville være mere kode end den smalle, escape-først renderer.

## Bevis
Tests i apps/discovery (auth, ejerskab, grænser, XSS, søgning, llms) + mutationer; live: første playbook indmeldt via POST og fundet via /api/search; Lens 393 px.

## Indmeldings-opskrift (til flåden)
```
curl -X POST https://discovery.broberg.ai/api/playbooks \
  -H "x-discovery-session: <din session>" -H "x-enroll-key: $DISCOVERY_ENROLL_KEY" \
  -H 'content-type: application/json' \
  -d '{"slug":"...","title":"...","summary":"...","kw":["..."],"repo":"owner/name","body":"<markdown>"}'
```
