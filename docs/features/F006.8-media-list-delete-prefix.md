# F006.8 — @broberg/media: list and delete everything under a folder

field #2874 (12/10 2026): when a customer field is deleted (field F006.4, GDPR) every object under the field's prefix in R2 must go, including objects field never recorded in its own list (e.g. crawl and delete overlapping). 0.4.0 has upload/get/delete/signedUrl/publicUrl but no listing, so an app can only delete what it noted.

## API (both providers)
- `list(prefix, { cursor?, limit? }) → { keys: string[]; cursor?: string }` — logical keys (the configured keyPrefix is stripped, like upload's return), sorted, at most `limit` (default and cap 1000, S3's page size), `cursor` present only when there is more.
- `deletePrefix(prefix) → { deleted: number }` — lists and deletes until nothing is left under the folder.

## The trap this refuses
As a plain string, prefix `kunder/1` also matches `kunder/10/…`. A GDPR delete would then delete another customer's files. **The prefix is a folder:** `kunder/1` and `kunder/1/` both mean everything under `kunder/1/`. `..`, backslash and NUL are refused as on upload. An empty prefix is allowed for `list` (everything under keyPrefix) and **refused** for `deletePrefix` (it would empty the store).

## Providers
- **r2:** S3 ListObjectsV2 (`GET ?list-type=2&prefix=&max-keys=&continuation-token=`), XML parsed without a dependency (Key, IsTruncated, NextContinuationToken; XML entities decoded). Deletion is per key with the existing `delete`, re-listing from the start each round, so no continuation token is used across deletes.
- **volume:** recursive walk of `objects/<prefix>/`, sorted; the cursor is the last key returned. The metadata file goes with each object (existing delete).

## Not proven here
R2 is tested against a fake S3 that answers real ListObjectsV2 XML; not against a live bucket. Said in the release report.

## Reuse
This is the shared package itself (@broberg/media). aws4fetch already signs the requests.

## Rollout
Minor 0.5.0 (new methods, nothing changed) via tag media-v0.5.0; clean install vs 0.4.0; report to field.
