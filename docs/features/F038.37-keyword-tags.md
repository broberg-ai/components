# F038.37 — Nøgleord som klikbare tags på hele Discovery

## Hvorfor
Christian 23/10 2026: «Lav ALLE nøgleord til klikbare tags throughout hele sitet». Nøgleordene (`kw` i `scripts/inventory-data.mjs`, typisk 10–25 pr. pakke, dansk og engelsk) er Discoverys bedste svar på «hvad har vi til X», men de vises kun som en kommasepareret linje på pakkesiden og ellers slet ikke.

## Scope
- Ens tag-stil i sitets chrome (`scripts/site-chrome.mjs`), så alle sider bruger samme komponent.
- Pakkesiden (F038.35): «Nøgleord» bliver en række tags; hvert tag er et link til `/packages?tag=<ord>`.
- `/packages?tag=X`: server-side filtreret til pakker hvis `kw` indeholder X (case-insensitive, hele nøgleordet), et synligt aktivt tag med en fjern-knap; fritekst-filteret virker stadig ovenpå.
- Fritekst-filteret (F038.34) får nøgleordene med i det, der matches på.
- Forsiden (`docs/inventory.html`, genereret af `scripts/build-inventory.mjs`): komponentkortenes nøgleord vises som de samme tags.

### Non-goals
- At ændre nøgleordene selv.
- En separat tag-oversigtsside (kan komme senere).

## Reuse
Discovery-sitets chrome og tokens; ingen ny pakke.

## Verifikation
Tests mod rosteret + Lens-flow pakkeside → tag → liste → fjern.

## Rollout
Push → discovery-workflow udruller → live-tjek.
