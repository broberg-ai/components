# F094.5 — Pager-rækken ombrydes ikke på telefon

## Fund
appkit 8/10 (#2220), Lens i rigtig browser, run f187e0e1. Ved 393 px er `.bdt-footer > .bdt-pager` («Rækker pr. side» + vælger + «Side 1 af 1» + fire knapper) 420 px bred, og `page-last` skubber hele siden 27 px sidelæns. Tabellen selv ruller korrekt i sin ramme; kun footeren går ud over kanten. Bryder D-55a2af uanset F094.3 (mobil-kort).

## Årsag
`.bdt-pager` er `display:flex` uden `flex-wrap`, og `.bdt-label` har `white-space: nowrap`. En flex-række uden wrap kan ikke blive smallere end summen af sine børn.

## Rettelse
- `.bdt-pager { flex-wrap: wrap; justify-content: flex-end }` — navigationsknapperne kan gå på næste linje.
- `.bdt-footer` og `.bdt-toolbar` får også `flex-wrap` og `min-width: 0`, og `.bdt-root { max-width: 100%; min-width: 0 }`, så ingen del af komponenten kan presse sin forælder bredere.

## Bevis
Vitest læser reglerne fra CSS'en (happy-dom har ingen layout). Den visuelle prøve er Lens ved 393 px på appkits side.

## Reuse
Rettelse i `@broberg/data-table` selv; intet nyt.
