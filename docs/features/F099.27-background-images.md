# F099.27 — Websideklip tager baggrundsbilleder med

## Motivation
jam #3566 (19/10 2026): Christian klippede fdaalborg.dk (WordPress + SiteOrigin-slider). Jam gemte 6 billeder, men siden har 16 indholdsbilleder: 6 `<img>` og 10 der kun findes som inline `style="background-image:url(…)"` i `<main>` (Lens e4ebb5de: 11 `.sow-slider-image-overlay` + 1 `.panel-background-overlay`). 0 problemer registreret, grænsen (50) var ikke årsagen.

Årsag: `createArticleExtractor` → `contentImages(article.content)` læser kun `<img>` fra Readabilitys output, og Readabilitys `_cleanStyles` fjerner `style`-attributter før. Baggrundsbilleder kan derfor aldrig klippes — og det rammer alle hero/slider/kort-gitter-sites.

## Scope
1. Før Readability: gå det ORIGINALE dokument igennem for elementer med inline `background-image: url(…)`. Kun hovedområdet: `main`, `article`, `[role=main]` hvis til stede, ellers `body` minus `header`/`nav`/`footer`. Spring over: svg, `data:image/svg`, gradienter, skjulte elementer (`hidden`, `aria-hidden`, `display:none` inline).
2. Deduplikér mod `<img>`-referencerne; send resten gennem samme `fetchImages` (min-størrelse 64, `maxImages`, byte-budget) — grænserne gælder stadig.
3. Readability taber dem i markdown → tilføj `![](url)` sidst i page-enheden. Jam omskriver `![..](url)` til R2 efter source_url.
4. `contentImages`: foretræk srcset/rigtig url frem for `src="data:,"`.

## Non-goals
- Computed style (CSS-filer, klasser) — kun inline style i første omgang; det dokumenterede tilfælde er inline. Udvides hvis en måling viser behov.
- Billeder i header/nav/footer (logoer, ikoner).
- Lazy-load via JS ud over `data-src` (Readabilitys `_fixLazyImages` dækker det).

## Test
Fixture efter fdaalborg.dk-formen: baggrunds-div i `<main>` → 1 asset; i `<footer>` → 0; gradient/svg → 0; samme url som `<img>` → én gang; `src="data:,"` + srcset → srcset-url. Mutationstjek.

## Reuse
Genbruger `fetchImages`/`ImageOptions` fra F099.23 (samme grænser, samme problems-rapportering). Ingen ny pakke; Discovery har ingen anden billedudtrækker.

## Rollout
Minor (web-clipper 0.20.0). Output ændres for sider med baggrundsbilleder (flere assets, `![](url)` sidst i page-enheden) — står i release-rapporten. Ren installation forrige vs ny. Jam måler fdaalborg.dk igen.
