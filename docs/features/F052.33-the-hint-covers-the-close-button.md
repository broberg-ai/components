# F052.33 — The hint covers the panel's close button

**Measured and photographed** by fd-sundhed on production 0.10.0: Lens flow-run
`e6fa490d-f3a4-40b5-b772-f8a29fd3fefe`, step-7. In fullscreen the `stage-bottom`
note sits **on top of** the picker panel's upper edge and hides its close ×.

## The third covered exit this week

The repetition is the finding, not the bug:

| | what covered what |
|---|---|
| F052.27 | the fullscreen exit landed under the **iOS status bar** |
| F052.27 | fd-sundhed's own × ended **under our fixed overlay** |
| **F052.33** | the hint we anchored to the stage covers **the panel's ×** |

Every one: a control that works, exists in the DOM, and passes every test that
asks whether it is *there* — and **cannot be reached**.

`document.elementFromPoint()` is the assertion that catches all three. It exists
in this package *because of* the second one. **It was never applied to the
panel's own close control** — we added it where we had been bitten and nowhere
else.

## The fix is not a z-index

Raising the panel above the note would leave a note on screen saying *«drag to
rotate · tap a body part»* while the user is choosing an intensity. **That advice
has stopped being true.**

The note is guidance for the **empty state**; the panel *is* the non-empty state.
They should never coexist. Stacking them treats a layout symptom and leaves the
wrong sentence on the screen.

## Why the consumer cannot fix it

Their words: there is no `onRegionOpen` / `activeRegion` to read, so they cannot
gate it — and they explicitly declined to write a **third** CSS wedge.

That is F052.31's rule applying again:

> If a consumer needs to know our internal structure to get what they want, it is
> a missing prop or a missing behaviour — not a missing selector.

Here it is a missing **behaviour**, and it is ours.

## Reuse

Nothing external. The reuse that applies is internal and is the point of the
card: `elementFromPoint` reachability, already established in this package by
F052.27, applied to a control it had never been pointed at.

## Non-goals

- Changing when the note shows in the empty state. F052.31 just handed that to
  the consumer.
- A general occlusion checker. Worth wanting; not this card.
