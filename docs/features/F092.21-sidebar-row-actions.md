# F092.21 — Rækkehandlinger på et sidebar-punkt

scout #2649 punkt 1 (scout-F011.2), godkendt mockup cardmem 01a11728 v7 (D-197c18).

## Ændring (app-shell, minor, additiv)
- `NavItem.actions?: NavAction[]`, hvor `NavAction = { id, label, icon?, kbd?, danger?, submenu?: NavAction[], input?: { value: string; placeholder?: string; saveLabel?: string } }`.
- `onItemAction?(navItemId, actionId, value?)` på AppShell/Sidebar.
- «…»-knap pr. punkt med handlinger: synlig ved hover/fokus, altid på touch (`@media (pointer: coarse)`), aria «Mere for <label>».
- Menuen: pop-over (position fixed fra knappen — samme teknik som F001.25's palet-liste), tastatur via ui-controls-core, kbd-genveje mens den er åben, danger i farezone-farve.
- Tre visninger i samme pop-over: liste · undermenu (tilbage-pil) · input (omdøb: felt + «Gem»).
- testids under `sidebar-item-<id>-…`.

## Reuse
Tastatur: `selectKeyReducer` fra @broberg/ui-controls-core; pop-over-placering som i app-shell's palet-dropdown (F001.25). Ingen ny pakke.
