# F092.22 — «…»-menuen får fokus, og «Slet» kan bekræftes i menuen

scout #2659 (11/10), målt med Lens på scout.broberg.ai (flows 157128bb + 83a9a810) mod app-shell 0.13.1.

## 1. Fokus (fejl i F092.21)
«…» åbnet med Enter → menuen vises, men `document.activeElement` er stadig «…», så P/R/D gør intet. **Årsag:** `RowActions` fokuserer menuen i samme layout-effekt, som beregner positionen — mens menuen endnu står `visibility: hidden`. Et skjult element kan ikke få fokus. Positionen sættes bagefter, men effekten kører ikke igen. F092.21's test sendte taster direkte til menuen (`fireEvent.keyDown(menu)`) og kunne derfor ikke se det.
**Rettelse:** fokus flyttes i en effekt, der kører, når positionen er sat (menuen synlig). Testen sender taster til `document.activeElement`, så den ser præcis det, brugeren gør.

## 2. Bekræft i menuen
Mockup v7: «Slet» → «Tryk igen for at slette» inde i menuen. `NavAction.confirm?: { label: string }`: første valg skifter label og lader menuen stå åben; andet valg kalder `onItemAction`. Lukning eller Escape nulstiller.

## Reuse
Udvider app-shell's egen RowActions; ingen ny pakke.
