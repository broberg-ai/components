# F094.2 — Træk-håndtag til rækker

Se F094. shadcn bruger dnd-kit, som kræver React. Vi bruger pointer events (én kodevej for mus og touch, `setPointerCapture`) og et tastatur-protokol som dnd-kit's: mellemrum løfter, pile flytter, mellemrum slipper, Escape fortryder, med en aria-live-region.

**Hvorfor slået fra ved sortering/filtrering:** så er skærmens rækkefølge ikke den gemte, og et træk ville gemme en rækkefølge brugeren ikke kan se. Samme valg som shadcn-eksemplet (rækkefølge = data-rækkefølge).

`moveRow(ids, from, to)` ligger i kernen som ren funktion.

## Reuse
Ingen flådepakke for DnD (Discovery 5/10). Ingen ny afhængighed.
