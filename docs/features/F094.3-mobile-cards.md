# F094.3 — Mobil: rækker som kort

**Kilde:** Christian 5/10 via appkit #1702: «Husk cards på mobile». Ved smal skærm er hver række et kort med kolonnerne stablet. Afkrydsning, træk-håndtag og ⋮-menu skal stadig kunne bruges. Ingen vandret rulning, heller ikke i tabellens ramme (D-55a2af).

## Design
Samme komponent, to layouts valgt med `useIsMobile` (768 px, samme grænse som app-shell). Kortets top: [afkrydsning] [håndtag] [primær kolonne som titel] [⋮]. Krop: øvrige synlige kolonner som `label: værdi`. Toolbar og fod bryder om til flere linjer i stedet for at rulle.

## Reuse
Samme kerne som F094.1; ingen ny afhængighed.
