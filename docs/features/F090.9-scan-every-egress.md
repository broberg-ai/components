# F090.9 — Samme scanner ved alle udgange

**Bestilt af:** Christian 4/11 2026 («Samme scanner før data … top-nutch secrets security»).

## Hvorfor
Git er kun én vej ud. En nøgle kan også forlade huset i en log-linje, en fejlrapport til Upmetrics (fejlbesked med en URL med `?token=`), en mail, et chat-svar eller en note i Trail. @broberg/secret-scan findes allerede; spørgsmålet er hvor den IKKE kører.

## Scope
1. **Kortlæg (målt, ikke antaget)** hver udgang med fil:linje:
   - @broberg/logger (kører redaction som standard — verificér)
   - @broberg/mail / mail-core (afsendelses-chokepoint, D-9c45f5)
   - Upmetrics SDK (`@upmetrics/sdk` — ejes af upmetrics)
   - Trail-skrivning (trail kører secret-scan — verificér version/F090.6-mønstre)
   - @broberg/chat-svar
   - cardmem/intercom-tekst (ejes af cardmem)
2. **Vores egne pakker** uden scanning får `redactSecrets` før afsendelse + test der planter en genereret nøgle og asserter streng lighed på den redigerede payload.
3. **Andres udgange**: bestilling via intercom med målingen vedlagt.

## Non-goals
- Personoplysninger (særskilt akse, redactPersonalData).
- At blokere afsendelse — vi redigerer, så indholdet når frem uden nøglen. (Mail kan blokere hvis ejeren ønsker det — spørgsmål.)

## Reuse
@broberg/secret-scan (≥0.16.0) overalt; ingen ny scanner.
