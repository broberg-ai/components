# F095.2 — Profil-klient og accountRoutes i @broberg/sso

Se F095. Bygger på F095.1 (getAccessToken).

## Design
- Klient: `getProfile(token)`, `updateProfile(token, name)`, `uploadAvatar(token, bytes, contentType)`, `removeAvatar(token)` — samme `appPost`/app-API-mønster som `addressOwnership` (origin-relativ, status først, så JSON).
- Klient-tjek før afsendelse: ≤ 2 MB, `image/png|jpeg|webp`.
- `accountRoutes({ client, tokenStore })` (hono): `GET /profile`, `POST /profile` `{name}`, `POST /profile/avatar` (rå body, Content-Type videre), `POST /profile/avatar/remove`. Kræver session; token via getAccessToken. Appen monterer på `/api/account`.
- 403 + `insufficient_scope` → SsoError der nævner `profile:write`.

## Reuse
appPost i sso; ingen ny afhængighed.
