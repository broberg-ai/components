# F092.15 — Brugermenuen nederst i sidebaren, med radiogrupper og zoom

Meldt af scout 9/10 2026 (#2415). Christian har godkendt Scouts mockups (cardmem mockup 01a11728…, v7): KAI-skallen, hvor brugermenuen sidder nederst i sidebaren og samler organisation, enhed og område-skift.

## API (additivt; standarden er uændret)
- `AppShell.userMenuPlacement: "topbar" | "sidebar-footer"` (standard topbar).
- `ShellUser.subtitle?: string` — fx «Administrator · Enhed Nord», vist under navnet.
- `userMenu.sections?: { id, label, items: { id, label, hint?, checked? }[] }[]` + `onSectionSelect(sectionId, itemId)` — radiogrupper. Appen ejer valget (som `language`).
- `userMenu.zoom?: { value, onChange, min?, max?, step? }` — − / % / +. Appen ejer værdien.
- Tema findes allerede (`appearance`, via @broberg/theme).

## Placering
Med sidebar-footer gengives UserMenu i sidebarens bund i stedet for toprækken; panelet åbner opad (bottom i stedet for top) og er venstrestillet. I icon-rail/foldet sidebar vises kun avataren.

## Ikke med
Søg ⌘K fra mockup v6 er ikke en del af ønsket.

## Reuse
Udvider @broberg/app-shell selv; tema via @broberg/theme som i dag. Ingen ny afhængighed.
