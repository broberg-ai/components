# F104.9.9 — Optagelsen ser ud som Google Meet

**Ejeren 3/11 2026 (ordret):** «Layout som Meet, kun den der taler og lav et API arg så det kan ændres til alle samtidigt i gitter.»

## Hvordan Meet gør (målt)

I fd-sundheds scope-møde «FD-sundhed og Complimenta API mangler» (Meet-optagelse i cardmem): den aktive taler fylder hele billedet med navn nederst, og videoen skifter, når en anden taler. Én fil.

## Løsning

LiveKit Egress har layouts til room composite: `grid`, `speaker` (taler stor + de andre små) og `single-speaker` (kun den aktive taler). Vores API får to værdier:

| Vores værdi | LiveKit-layout | Hvad man ser |
|---|---|---|
| `speaker` (standard) | `single-speaker` | kun den der taler, som Meet |
| `grid` | `grid` | alle samtidigt |

- voice-control: `POST /v1/recordings` tager `layout?`; ukendt værdi → 400 før noget startes. Optagelsen husker sit layout, så en genstart («Start signal not received») bruger samme.
- `@broberg/call`: `startRecording(room, opts, { layout })`.

## Ikke i scope

- «Taler stor + andre små» (`speaker` hos LiveKit) — ikke bedt om; kan tilføjes som tredje værdi.
- At vise skærmdeling anderledes — LiveKits single-speaker viser en skærmdeling, når den findes.

## Reuse

Ingen ny pakke: LiveKit Egress' egne layouts; udvidelse af voice-control og `@broberg/call` (vores).

## Bevis

Enhedstests (layout-mapping, afvisning) + live-optagelse med to deltagere i begge layouts, kontrolleret på stillbilleder fra filerne.
