# F092.20 — Sidebar-historik: markør, pin og plain gruppe med dag-underoverskrifter

scout #2649 (scout-F011.2) — deres godkendte chat-mockup (cardmem 01a11728 v7, sidebar «Historik», kontrakt D-197c18) har en historik, som app-shell's NavItem ikke kan udtrykke. Denne story dækker punkt 2 og 3; punkt 1 (rækkehandlinger) er F092.21; punkt 4 findes allerede (`title={it.label}` på hvert punkt).

## Ændring (app-shell, minor, additiv)
- `NavItem.marker?: "working"` → en markør (prik, token `--accent`) foran label, aria-label «Arbejder»/«Working».
- `NavItem.pinned?: boolean` → pin-ikon efter label, aria-label «Fastgjort»/«Pinned».
- `NavGroup.variant?: "default" | "plain"` → plain = label i normal skrift og vægt (ikke uppercase/mono).
- `NavGroup.sections?: { label: string; items: NavItem[] }[]` → underoverskrifter inden i én gruppe. `items` og `sections` kan kombineres (items først).
- Uden de nye felter: samme output som 0.11.1.

## Reuse
Udvider app-shell's egen NavItem/NavGroup; ingen ny pakke. Farver er theme-tokens.
