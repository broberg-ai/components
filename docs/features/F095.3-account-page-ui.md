# F095.3 — AccountPage i app-shell

Se F095. Bygger på F095.2 (accountRoutes).

## Design
- `<AccountPage lang adapter? />` i `@broberg/app-shell/preact`. Adapter: `{ load(), saveName(name), uploadAvatar(file), removeAvatar() }` → alle returnerer profilen; standard = fetch til `/api/account/profile*`.
- **Gem viser serverens svar** (CLAUDE.md «Et gem-felt SKAL bevises at gemme»): feltet sættes til det svarede navn, aldrig optimistisk. Test hvor serveren returnerer en anden værdi end den tastede.
- Avatar genbruger `Avatar` (F092.3). Upload via skjult `<input type=file accept="image/png,image/jpeg,image/webp">` bag en custom knap; størrelse/type tjekkes før upload. Fjern med custom bekræftelse inline (ingen confirm()).
- «Sikkerhed i Broberg ID» → account_url via NavLink (ekstern → ny fane, F092.10).
- Beskaering: ikke i v1 (CSS gør den rund); kan komme senere.

## Reuse
Avatar, NavLink og TEXT fra app-shell; @broberg/sso's accountRoutes som standard-backend.
