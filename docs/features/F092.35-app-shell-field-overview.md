# F092.35 — app-shell: bundmenu, begrænset udseende, tema først, overstyrbare tekster

> **Udløser:** field intercom 3748, 22/10 2026. Ejeren har bestemt at Fields overblik skal følge de godkendte mockups (cardmem 01a12b0a overblik, 01a15906 Data; field-kort F007.8). field vil ikke kopiere eller CSS-overstyre app-shell lokalt.
> **Status:** backlog — ikke bygget.

## De fire udvidelser (alle additive)

1. **`mobile: "bottom-nav"`** ved siden af `"drawer"`/`"rail"`: nav-items som fast bundbjælke på telefonbredde. Aktiv fane markeret (`aria-current="page"`), `data-testid` på hver fane, roden får standard-testid eller det appen giver (`mobileNavTestId`), `padding-bottom: env(safe-area-inset-bottom)`. Kun top-niveau-punkter; undermenuer åbnes ikke herfra.
2. **`userMenu.appearance: { palette?: boolean; surfaces?: boolean }`** — `false` skjuler rækken, så kun Lys/Mørk/System står tilbage.
3. **`appearancePosition: "top" | "bottom"`** — tema-blokken før «Konto».
4. **`strings?: Partial<Record<Lang, Partial<ShellStrings>>>`** — overstyr shell-tekster pr. sprog (fx sidebar-knappen «Toggle sidebar», tema «Lyst/Mørkt/System»). Ikke-overstyrede nøgler bruger pakkens tekst.

## Non-goals

- Ingen ændring af standardudseendet.
- Ingen ny navigationsmodel på desktop.
