# F104.9 — Optagelse af opkald

> **Ordre:** ejeren 2/11 2026, ordret: «A, 365 dage, ja opret det hele» — svar på planen i Comms (01a198d7…): **A** = hele mødet som én video, **365 dage** og så automatisk sletning, **GO** til hjælpetjeneste og lager. Prisløftet i planen: ingen fast pris for optagemaskinen — den kører KUN mens der optages (~USD 0,15–0,20/optagetime `[Likely]`); fast ~USD 3–5/md.

## Arkitektur
```
app-server ──startRecording()──► broberg-voice-control (lille, auto-start)
                                   1. starter optage-maskinen (Fly Machines API, egen app-token)
                                   2. venter til den er klar
                                   3. beder LiveKit starte en «room composite»-optagelse
                                   └─ stopper optage-maskinen igen, når ingen optagelse kører (tjek hvert minut)
broberg-voice (LiveKit) ◄── Redis (broberg-voice-redis, privat netværk) ──► broberg-voice-egress (LiveKit Egress, Chrome)
                                                                               └─ fil → R2 (EU-jurisdiktion), slettes efter 365 dage
```
- **Redis**: egen lille Fly-app i arn (redis:7-alpine, 256 MB, kun privat netværk, adgangskode i vault). LiveKit og Egress kræver den for at tale sammen.
- **Egress**: Fly-app i arn, performance-maskine (Chrome render), **stoppet som udgangspunkt**. Startes kun af control.
- **Control**: lille Fly-app i arn med HTTP og auto-start; kald godkendes med appens LiveKit-nøgle (samme som billetter). Den eneste med en Fly-token til egress-appen.
- **Lager**: R2-bucket med EU-jurisdiktion og livscyklus-regel 365 dage, oprettet af cardmem (D-4092fb).
- **Pakken @broberg/call**: `startRecording(room)` / `stopRecording(id)` på `./server` (kalder control), webhook-hændelserne `egress_started/egress_ended` via den eksisterende `verifyWebhook`, og en `recording`-tilstand i klienten så alle ser «Optager nu».
- **Samtykke**: formål `call-recording` i BID (D-ae49a8). Appen må kun starte en optagelse, når alle deltagere har givet samtykke (model A optager alle).

## Trin
1. Redis-app — oppe, kun privat netværk, LiveKit forbundet.
2. Egress-app — kan optage et testrum til R2 når den er tændt.
3. Control — tænder/slukker egress efter behov; måles: maskinen er stoppet når ingen optager.
4. R2-bucket (cardmem) med 365-dages sletning.
5. Pakken: startRecording/stopRecording + recording-tilstand (0.3.0).
6. BID: formålet `call-recording`.
7. Live-bevis: et 2-personers testopkald optages, filen ligger i R2 og kan afspilles; egress-maskinen er stoppet bagefter.

## Ikke i scope
Transskription, redigering, afspiller-UI.

## Reuse
LiveKit Egress (open source), R2 via cardmem, BID-samtykke, @broberg/call.
