# F005.25 — Kode- og magic-link-mail: én fælles skabelon

**Bestilt af:** Christian 25/10 2026 («God ide»), via buddy #4887. Flåderegel annonceret i #4889: projekter bruger skabelonen når den er ude og bygger ikke deres egen.

## Motivation
Christian så «Kopiér kode» i Gmail på en Microsoft-mail. Den knap tegner Gmail selv («Baseret på denne mail · Korrekt?»); iOS tilbyder tilsvarende autofyld. En mail kan ikke selv have en kopier-knap, fordi mailprogrammer ikke kører kode. Det vi KAN gøre er at skrive mailen så koden er let at genkende. I dag bygger hvert projekt sin egen kode-mail, så oplevelsen er forskellig, og ingen ved om Gmail genkender den.

## Scope
- `codeMail()` i @broberg/mail-core: tager kode, produktnavn, gyldighed, evt. magic link og tekster; returnerer `{ subject, html, text }` bygget på de eksisterende byggeklodser (renderShell, cta, paragraph).
- Emne: «Din kode til {produkt}: {kode}» (teksten kan gives ind, men skal indeholde koden).
- Koden: ét element, stor monospace, cifrene sammenhængende i teksten, afstand KUN via CSS letter-spacing. Aldrig billede.
- Ren tekst-udgave med koden alene på egen linje.
- Magic link: én knap + linket skrevet ud som tekst under den. Kun absolutte https-links.
- Kontrol: et andet langt tal i samme mail giver en navngiven advarsel; en kode uden for 4–10 tegn afvises.
- Lys og mørk tilstand med målt kontrast.

## Non-goals
- At sende mailen (det gør @broberg/mail som i dag).
- At generere eller gemme koden — det er appens/BID's.
- Lagring af skabeloner (D-00798e: cardmems).

## Usikkert, og derfor målt i stedet for antaget
Gmail og Apple oplyser ikke deres kriterier. Antagelsen at sammenhængende cifre er vigtigere end synlig afstand er [Likely], ikke målt. Den manuelle AC sender en rigtig testmail til ejeren og ser efter knappen i Gmail web, Gmail iOS og Apple Mail. Virker det ikke, prøves varianter (emneformulering, kodelængde) og resultatet skrives på kortet.

## Reuse
Discovery: mail-familien er stedet — @broberg/mail-core (HTML-byggeklodser) og @broberg/mail (afsendelse). Ingen ny pakke, ingen ny dependency. Genbruger renderShell, cta, contrastRatio/readableInk og samme URL-regel som mail-templates' checkUrl.

## Rollout
Minor af @broberg/mail-core. Release-rapport til forbrugerne (D-b7eb14), Discovery-rækken opdateres, buddy får besked så flådereglen kan pege på den.
