# F084.154 — fetchTicket: hent en BID-billet uden nøgle

Krydsreference: broberg-id-F087.10 (Fly-tjenester flyttes én ad gangen) og F087.11 (guiden). Christian 9/10: Mac-sessioner og nøgle-allowlisten røres ikke nu.

## Hvorfor
Billet-modtagersiden findes (F084.153, F038.24). Afsendersiden er i dag håndskrevet i BID's ticket-probe.yml. Skal hver Fly-tjeneste gøre det samme, ender flere repoer med hver sin kopi af vekslingen. Den hører hjemme i @broberg/sso.

## Design
`fetchTicket({ audience, scope?, issuer? })` (og `createTicketClient` til egen cache/injektion):
1. Arbejds-identitet: Fly (FLY_APP_NAME + /.fly/api-socket) → POST /v1/tokens/oidc {aud: issuer}. GitHub Actions (ACTIONS_ID_TOKEN_REQUEST_URL + _TOKEN) → GET ...&audience=issuer. Ellers NoWorkloadIdentityError.
2. POST {issuer}/oauth2/token, form-encoded: grant_type=urn:ietf:params:oauth:grant-type:token-exchange, subject_token, subject_token_type=urn:ietf:params:oauth:token-type:jwt, audience, scope.
3. Cache pr. (audience, scope) til 30 s før exp.
4. Fejl: TicketExchangeError {code, status} — code er BID's fejlnavn før kolon i error_description. Netværksfejl/5xx er forbigående.

Billetten logges aldrig.

## Reuse
Udvider @broberg/sso (vores egen), ingen ny afhængighed. Unix-socket via node:http (virker i Node og Bun).
