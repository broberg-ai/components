# F099.10 — Claude artifacts in the clip as FILES, and a clip that skips something says so

> Story under F099. Priority high. Owner order 13/10: «Kan vi gemme artefakterne nu?»

## Motivation
- jam measured (#3189, ~15:05 Danish time 13/10): the «KAI» conversation on claude.ai gave **74 of 79 turns** with 0.5.2, the artifacts were missing, and the clip still said `complete: true`.
- Cause: claudeReader keeps only content blocks of type `text`. An artifact is a `tool_use` block (create / rewrite / update with the artifact's id, title, type and content), so its content was dropped — and a message that consisted only of an artifact became empty and vanished, which is where the 5 missing turns went.
- Owner's decision for Jam (#3188): artifacts are saved as FILES in the EU store (destination.uploadAsset → R2), not only as text in the turn.

## Design
- Each artifact operation becomes an `Asset` on the turn it belongs to: `{ type: "file", id, name: title, mime, content, version }`, where `content` is the artifact AS OF that turn — an `update` (old_str → new_str) is applied to the previous version, `rewrite` replaces it.
- The turn's markdown gets a short reference (`[Artefakt: <title>]`), so the fingerprint is stable and a turn made only of an artifact is no longer empty.
- `Asset.url` becomes optional and `name`, `mime`, `content`, `id`, `version` are added (a type change: say so in the release report).
- Tool calls Claude makes for files (`create_file`/`str_replace`, the newer form) are read the same way.
- **Honest completeness:** an unknown content block type, or an update that cannot be applied (the old text is not in the previous version), makes the clip `complete: false` with the reason. Known non-content (thinking, web search calls and results) is skipped without marking.

### Rejected
- Artifacts only as markdown inside the turn: the owner wants files.
- Silently skipping unknown blocks: the measured bug — 74 of 79 reported as complete.

## Consequence for consumers
Positions and fingerprints change for conversations with artifacts (turns that were dropped now count). An append-only destination sees a new branch, not duplicates — said in the release report.

## Reuse
Extends @broberg/web-clipper (the existing Unit.assets / uploadAsset contract). No new package.

## Risk
The artifact block shape is taken from claude.ai's known message format, not measured live by us (we cannot sign in). jam measures on «KAI».

## Rollout
Minor release 0.6.0 (Asset type change), report to jam + trail.
