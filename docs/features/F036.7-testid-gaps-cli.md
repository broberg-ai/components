# F036.7 — testid-gaps som pakke + CLI

**Bestilt af:** appkit 10/10 2026 (#2487, deres F012.1). **Godkendt af ejeren af reglerne:** cardmem 10/10 (#2489).

## Behov
En CI-port, der fejler, når et interaktivt element mangler `data-testid` (F086-reglen). I dag findes tjekket kun som daemonens `POST /lens/testid-gaps`, og CI kan ikke nå en lokal daemon. To scannere ville glide fra hinanden.

## Løsning
1. Flyt `gapsInFile` (cardmem `apps/agent/src/lens/manifest.ts:523`) og dens hjælpere ORDRET til `@broberg/lens` som ren funktion. Ingen forbedringer i samme omgang.
2. cardmems tests flyttes med som fixtures, så pakken beviser samme adfærd.
3. Bin `testid-gaps <dir>`: `file:line` pr. fund, exit 1 ved fund, exit 0 ved rent træ med antal scannede filer, fejl ved 0 scannede filer (et tomt træ må ikke blive grønt i stilhed).
4. cardmem skifter daemonens endpoint til pakken på eget kort, når versionen er ude.

## Regler
Hvad der tæller som interaktivt, er cardmems beslutning. Ændringer aftales med dem først.

## Reuse
Udvider eksisterende @broberg/lens; ingen ny pakke. Discovery: ingen eksisterende CI-scanner (søgt af appkit: testid, testid-gaps, interactive testid).
