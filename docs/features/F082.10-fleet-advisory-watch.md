# F082.10 — Fælles daglig sårbarheds-vagt for flåden

> Story under F082. Foreslået af bid 24/10 2026 (#4316) med Christians ja.

## Hvorfor
zod-hullet (GHSA-mrhx-c7xc-m3w5) blev fanget af BID's daglige advisory-watch (F084.189/.190) — kun BID har det. components' eget tjek kører ugentligt og havde først set det mandag. Hvert repo skal have samme dagsvagt, uden at hver bygger sin egen.

## Hvad BID har (bevist i drift)
- `advisory-watch.yml`: dagligt + dispatch; kører repoets audit-spærre (`bun audit --json`) med kvitteringsliste — high/critical blokerer, medmindre kvitteret med begrundelse; «kunne ikke tjekke» er rødt, aldrig grønt.
- `advisory-alarm.ts`: én GitHub-sag pr. GHSA, Upmetrics-incident `dependency_vuln` (mail + Discord via upmetrics' regel, højst dagligt), begge lukkes når hullet er væk. Upmetrics-nøgle via OIDC.

## Scope
1. Port til components som genbrugelig workflow (`workflow_call`, versioneret tag) + script; npm, pnpm og bun.
2. OSV.dev som anden kilde (fra F082.9) + CISA KEV-markering.
3. Dagligt ur via cronjobs.webhouse.net; GitHub-cron som backup.
4. Pilot: components + BID (BID skifter fra egen kopi uden at miste alarmer). Derefter cardmems F401-hygiejne til alle projekter.

### Non-goals
Ingen container-scanning (nat-motoren). Ingen auto-rettelse (Renovate).

## Reuse
BID's kode er kilden — porteres, ikke genopfindes. F082.9 leverer OSV-delen.

## Åbne spørgsmål
- Hvor bor kvitteringslisten: i det kaldende repo (fil) — foreslået.

## Bygget (24/10, første del)
- `scripts/advisory/engine.mjs` — beslutningen (ren, uden netværk): audit-JSON for npm/pnpm/bun → fund; låste pakker fra lockfilen → OSV; kvitteringsliste valideres (ingen begrundelse = rød); `decide` → clean/blocking/error; `planAlarm` (error lukker intet, én `[audit-error]`-sag). BID's titelformat bevaret.
- `scripts/advisory/watch.mjs` — kører i det kaldende repo: `--mode gate` (kun exitkode) eller `--mode watch` (GitHub-sager + Upmetrics via OIDC som BID). gh-fejl (inkl. 403 rate limit) = rød.
- `.github/workflows/advisory-watch.yml` — `workflow_call`; motoren checkes ud fra components på `engine-ref`. Inputs går til shell som env.
- `scripts/test-advisory-engine.mjs` (i `test:root`): 11 tjek; 6 mutationer fanget.
