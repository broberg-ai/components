# F092.13 — ConfirmDialog i @broberg/app-shell/preact

## Kilde
appkit 8/10 (#2218), til appkit-F015.2: «Slet» i data-tablens ⋮-menu skal bekræftes i et custom vindue. Ingen native `confirm()`/`<dialog>` (D-4cd764). Hverken app-shell 0.8.0 eller ui-controls-core har en Preact-ConfirmDialog; ui-controls-core siger at visningen er per stak.

## API (appkits forslag, taget som det er)
`<ConfirmDialog open title body confirmLabel cancelLabel destructive busy error onConfirm onCancel testId />`

- `role="alertdialog"`, `aria-modal`, titel og brødtekst koblet via aria-labelledby/describedby.
- Åbner med fokus på **Annuller** (den sikre knap), holder Tab inde i vinduet, og giver fokus tilbage til det der havde det før.
- Escape og klik på baggrunden = onCancel. Mens `busy`: begge knapper deaktiveret, og hverken Escape eller baggrund lukker — ellers kan man «annullere» en sletning der allerede er sendt.
- `error` vises i vinduet som `role="alert"`; vinduet bliver åbent så man kan prøve igen eller annullere.
- `destructive` = rød bekræft-knap (`--danger`).
- Danske standardtekster (Bekræft/Annuller), testid-præfiks (default `confirm-dialog`).
- CSS i `css/app-shell.css` under `bas-`-præfikset, kun theme-tokens.

## Test
Vitest + happy-dom, læst fra DOM med streng lighed; mutationstjek på fokus, Escape, baggrund, busy-lås og error.

## Reuse
Discovery 8/10: søgning på confirm dialog / modal / dialog gav kun `@broberg/ui-controls-core` (logik, ingen visning) og `@broberg/chat`. Bygges i `@broberg/app-shell`, som allerede er Stack B-UI'et appkit bruger.
