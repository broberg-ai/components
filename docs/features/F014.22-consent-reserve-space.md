# F014.22 — the banner can reserve space at the bottom

broberg-ai #2911 (Christian's choice 12/10, their card F049.2), running 0.6.0: the banner is `position: fixed` at the bottom and, while open, covers the bottom of the page — on a phone the footer's last links cannot be scrolled clear of it until a choice is made.

## Fix (opt-in, default unchanged)
1. `reserve-space` attribute on `<broberg-consent>`: while the banner is shown, `<html>` gets `padding-bottom` = distance from the banner's top to the viewport bottom (its height + `--broberg-consent-banner-bottom`), kept current by a ResizeObserver on the banner and on window resize. On a choice it is removed, and any inline padding-bottom the site had on `<html>` is restored exactly.
2. Always: the host reflects the state as `data-banner-open` while the banner is shown, so a site can reserve space its own way without reaching into the shadow DOM.
3. Without `reserve-space` the document is never touched.

Related, not this card: F014.17 (banner position variables) — the variables are in the code; its card is still open.
