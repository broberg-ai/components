# F082.7 — @broberg/media-transform leverer sårbare afhængigheder

## Hvorfor
Det første afhængigheds-tjek (F082.5, 23/10 2026) fandt 2 høje sårbarheder i det `@broberg/media-transform` v0.1.0 leverer. Samme pakke er udgivet uden Trusted Publisher (F038.31 viser «ingen provenance»), så den næste udgivelse bør også ske via CI.

## Scope
- `pnpm audit --prod` i `packages/media-transform` → sårbare afhængigheder og rettede versioner.
- Opgradér, test, udgiv patch via publish.yml (Trusted Publisher), release-rapport.
- Kør afhængigheds-tjekket igen og commit.

### Non-goals
- Nye funktioner i pakken.
