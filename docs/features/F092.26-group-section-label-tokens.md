# F092.26 — tokens for gruppe- og dag-overskrifter + ikke-foldbar gruppe

scout #2728 (11/10). 0.16.0 er i drift hos scout (rækker 40px top-til-top og 17px på prod, Lens b7c8b283). Næste afvigelse fra mockup v7 i sidebaren:
- «Historik» (gruppeoverskrift): 15px, --fg-muted, ingen fold-chevron (bare tekst), padding 14px 10px 6px.
- «I dag»/«I går» (sektionsoverskrift): 13.5px, --fg-muted, normal skrift (ikke mono/versaler).

## Målt i dag
- `.bas-group__label` er en fold-knap med chevron: mono, 10px × skala, letter-spacing .08em, versaler, --fg-subtle, padding 6px 4px 4px. Plain-varianten: inherit, 12.5px, ingen versaler, 500, --fg-muted.
- `.bas-section__label`: 11.5px × skala, --fg-subtle, padding 6px 10px 2px.
- Ingen tokens; en gruppe med label kan altid foldes.

## Ændring (app-shell, minor, additiv)
1. Gruppeoverskrift-tokens, fallback = dagens værdi pr. variant: `--bas-group-label-font-size`, `-color`, `-transform`, `-font-family`, `-padding`, `-letter-spacing`, `-font-weight`.
2. Sektionsoverskrift-tokens: `--bas-section-label-font-size`, `-color`, `-padding`, `-transform`, `-font-family`.
3. `NavGroup.collapsible?: boolean` (default true). `false`: overskriften renderes som tekst (`div.bas-group__label.bas-group__label--static`, ingen knap, ingen chevron, intet aria-expanded), gruppen er altid åben (en gemt foldning ignoreres). testid `sidebar-group-<slug>` på overskriften, som før.
- README + eksempel-appen (`?v7` udvides).
