# F029.14 — Sidebar group testid stable across languages

## Why
buzzalert (#5146, 27/10 2026): `@broberg/app-shell`'s sidebar builds a group's `data-testid` from the TRANSLATED label (`preact.tsx` ~l.762: `slug = label.toLowerCase().replace(/[^a-z0-9]+/g, "-")`). So the testid changes with the language and Danish letters are stripped: «Opsætning» → `sidebar-group-ops-tning`, English «Setup» → `sidebar-group-setup`. A testid must be stable across languages — it is the anchor Lens drives (F086).

## Scope
- `NavGroup.id?: string`. When set it replaces the label-slug in every testid the group renders (`sidebar-group-<id>`, `sidebar-group-<id>-unlabelled`, the action fallback `sidebar-group-<id>-action`).
- Without `id`: unchanged output (additive, not breaking).

## Non-goals
- The stored fold state is still keyed by `label` (a language switch forgets which groups were folded). Noted as a follow-up, not changed here.
- No automatic transliteration of æøå in the fallback slug — that would change existing testids.

## Reuse
No shared primitive for this; app-shell owns the sidebar.

## Tests
Same `id` → same testid for a Danish and an English label; no `id` → identical to 0.25.2; mutation that ignores `id` goes red.

## Rollout
Minor release of `@broberg/app-shell`, roster bump, release report to buzzalert (D-b7eb14), stated as a possibility (D-5f65b6).
