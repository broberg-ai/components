# F001.17 — the broberg.ai palette in @broberg/theme

## Why

trail (intercom #1413), on Christian's order 1/10 2026: a third theme in Trail's picker, "Broberg.ai", next to Light and Dark. The palette exists today only as copies: broberg-id/ui/src/app.css ("HUSETS TOKENS — samme værdier som brand.ts") and the broberg.ai site. Trail would become copy number three. One source instead.

## Design

Two new variants, `dark-broberg` and `light-broberg`. The `dark-`/`light-` prefix is load-bearing: the preset's Tailwind `dark` custom-variant is `[data-theme^="dark"]`, so a key named `broberg-dark` would silently render dark colours with light-mode utilities.

Values are BID's house tokens, mapped onto the preset's shadcn vocabulary:

| shadcn token | BID token (dark / light) |
|---|---|
| background | --color-bg (#23282f / #f5f7fa) |
| foreground | --color-fg (#f0f4f8 / #161b22) |
| card | bg + card overlay, made opaque (dark) / #ffffff (light) |
| popover | --color-surface-float (#1c2027 / #ffffff) |
| primary / primary-foreground | --color-primary / --color-on-primary |
| muted / muted-foreground | --color-bg2 / --color-muted |
| accent (a HOVER surface in shadcn) | --color-hover |
| border / input | --color-border |
| ring | primary |
| sidebar | --color-bg2 |

**The brand orange is not shadcn's `accent`.** shadcn's `--accent` fills hovered menu rows; BID's `--accent` is the brand orange. Mapping one onto the other would paint every hovered row orange. So the orange ships as `--brand-accent` (a fill) and `--brand-accent-text` (the readable text variant), in both broberg variants only.

Fonts (DM Sans / DM Serif Display) are NOT shipped: they are self-hosted files per app (BID's reasoning: no Google Fonts IP leak). Radius follows BID's card (12px → `--radius: 0.75rem`).

## Release

0.9.0 (minor): additive CSS + two new ThemeKeys. Not breaking at runtime; an exhaustive `switch` over ThemeKey gets a compile error, which the release report says out loud.

## Reuse

This IS the shared theme package; the alternative (Trail copying BID's file) is the drift it exists to prevent. Values sourced from broberg-id/ui/src/app.css @ main, 1/10 2026.
