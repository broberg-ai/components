# F021.10 — En klassisk service worker kan få «Opdatér nu»

sales #2606 (sales-F001.7): appkit-lean-apps har en KLASSISK service worker i `public/` (`importScripts("/sw.global.js")` fra @broberg/webpush). `@broberg/pwa/sw` findes kun som ES-modul, så `listenForSkipWaiting` kan ikke hentes ind uden at hver app laver sin egen kopi.

## Ændring (pwa, minor)
- Ny tsup-entry `pwa-sw` i format `iife` → `dist/pwa-sw.global.js`, samme mønster som webpush' `sw.global.js` (F067).
- Filen hæfter selv lytteren på (`listenForSkipWaiting(self)`) og sætter `self.BrobergPwa = { listenForSkipWaiting, SKIP_WAITING }`.
- **Navnet er `pwa-sw.global.js`, ikke `sw.global.js`**: begge filer kopieres til `public/`, og samme navn ville lade den ene overskrive den anden.
- `exports["./sw.global"]` peger på filen.

## Brug
```js
// public/sw.js
importScripts('/sw.global.js');      // @broberg/webpush
importScripts('/pwa-sw.global.js');  // @broberg/pwa — «Opdatér nu» virker
```

## Reuse
Kopierer webpush' byggemønster; kildekoden er pwa's egen `sw.ts`, ingen ny logik.
