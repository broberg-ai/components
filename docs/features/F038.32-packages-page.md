# F038.32 — «Packages»: alt om alle vores pakker på én side

## Hvorfor
Christian 23/10 2026: «Lav et menupunkt der hedder Packages med ALT info samlet om alle vores pakker». Forsiden viser pakkerne som kort fordelt på lag; der er ingen samlet tabel man kan sortere i, og flere oplysninger (hvor mange repos der bruger pakken) står kun i FLEET-sektionen.

## Scope
- `/packages` (server-renderet, bag login som resten) i sitets design (`scripts/site-chrome.mjs`), menupunkt «Packages» (nav-packages) i topbjælken på alle sider.
- Én række pr. udgivet `@broberg`-pakke: navn, version, npm-link, udgivet (dansk tid), Trusted Publisher, lag, ejer, install-kommando, antal forbrugende repos (fra `data/fleet-deps.json`), og afhængigheds-status når F082.5 leverer den.
- Sortering pr. kolonne (lille inline-JS, knapper med testids).

### Non-goals
- Redigering. Siden læser kun.

## Arkitektur
Genbruger `docs/npm-meta.json` (F038.31), rosteren (`scripts/inventory-data.mjs`) og flåde-scannet; renderes i Discovery-serveren som /tickets.

## Reuse
Intern til Discovery; ingen @broberg-pakke ejer sitets sider.

## Rollout
Commit → deploy → mål live (rækkeantal = /api/packages).
