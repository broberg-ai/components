# F094.4 — Eksempel, Lens og udgivelse

Se F094. En ny pakke kan ikke udgives af CI første gang (ingen Trusted Publisher endnu), så 0.1.0 kræver Christians `npm login` + 2FA-kode — samme vej som app-shell 0.1.0. Derefter sætter han Trusted Publisher op, og 0.1.1+ går via CI.

Eksemplet genskaber dashboard-01's tabel (Outline/Past Performance/Key Personnel/Focus Documents-faner, Section/Status/Target/Limit/Reviewer-kolonner) med fiktive data, så Lens kan tage skærmbilleder ved 393 og 1440 px. appkit bygger derefter tabellen ind i starteren (appkit-F015.2).

## Reuse
Eksemplet bruger app-shell + theme; ingen nye afhængigheder.
