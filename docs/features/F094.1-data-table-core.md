# F094.1 — Kerne + desktop-tabel

Se F094 for kilde og samlet design.

## Indhold
- `@broberg/data-table` (kerne, ingen framework): `sortRows`, `filterRows`, `paginate`, selection-helpers (all/some/none → indeterminate), `visibleColumns` med localStorage-persistens. Rene funktioner, testet hver for sig.
- `@broberg/data-table/preact`: `<DataTable columns rows getRowId … />` med toolbar (søg, Tilpas kolonner), tabel, fod (valgt-tekst, rækker pr. side, side x af y, 4 navigationsknapper).
- Kolonnedefinition: `{ id, header, cell?: 'text'|'badge'|'status'|'number'|'select'|render-fn, sortable?, align?, hideable?, options? }`.
- Dropdowns og ⋮-menu bygget på `@broberg/ui-controls-core` (`selectKeyReducer`, `makeOutsideClickHandler`).
- Motor-valg: egne rene funktioner frem for @tanstack/table-core (se F094). Hvis F094.2/.3 viser at vi genopfinder for meget, skiftes der — det skrives i handoff.

## Testmål
Vitest + happy-dom, læst fra DOM med streng lighed; mutationstjek på sortering, filtrering, sidevisning, halv-tilstand og persistens.

## Reuse
`@broberg/ui-controls-core`, `@broberg/theme`. Discovery havde ingen tabel-pakke (søgt 5/10).
