# F017.7 — onSaveSucceeded i settings-bussen

appkit #2658 (11/10, F005.1), målt med Lens: to «Gemt»-toasts efter ét tryk. `onSaved` kaldes af `markSaved()`, og appkit kalder `markSaved()` efter at have hentet værdierne (for at nulstille en ugemt tilstand fra et tidligere besøg). En toast på `onSaved` siger derfor «Gemt» ved hver indlæsning.

## Ændring (settings, minor, additiv)
- `DirtyBusHandlers.onSaveSucceeded?: () => void` — kaldes kun, når `requestSave()` lykkedes (alle paneler gemte), én gang pr. gemning. Ikke ved `markSaved()` og ikke ved en fejl.
- `onSaved` uændret (betyder «formularen er ren igen», hvad end årsagen er).
- Preact: `useDirtyBus` udstiller den ikke; den bruges via `onDirtyBus({ onSaveSucceeded })`, og README viser toast-mønsteret.

## Reuse
Udvider settings' egen bus.

## Også rettet (samme fejl)
`SettingsSaveButton` viste «Gemt» på `onSaved` og blinkede derfor også ved et manuelt `markSaved()`. Den lytter nu på `onSaveSucceeded`. Udgivet i 0.2.0.
