# F092.27 — org-linje i brugermenuens top + tokens tager ikke CSS-nøgleord

scout #2740 (11/10), chat-mockup v7 række 2.1.

## 1. Organisationen i menu-toppen
Mockuppen: brugermenuens top viser avatar, navn, email OG en org-linje med bygnings-ikon («broberg.ai»). Sidebar-foden viser undertitlen («Ejer · Ledelse»). I dag har `ShellUser` kun `subtitle`, som vises begge steder.

Ændring (additiv): `ShellUser.org?: string` vises kun i menu-toppen, som en linje med bygnings-ikon (lucide building, 15px, --fg-muted, 13px tekst), testid `user-menu-org`. Undertitlen er uændret begge steder.

## 2. Tokens og `inherit`
scout satte `--bas-group-label-font-family: inherit` og fik mono. Målt årsag: et CSS-globalt nøgleord (`inherit`, `initial`, `unset`) som værdi af en custom property gælder VARIABLEN, ikke ejendommen. Variablen arver så fra forælderen, hvor den ikke er sat, og `var()` bruger sin fallback (mono). Det er CSS-reglen, ikke en fejl i default. README får en linje: brug en rigtig værdi, fx `var(--font-sans)`.
