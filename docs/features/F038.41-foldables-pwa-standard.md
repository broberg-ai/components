# F038.41 — Foldeskærm-standard for alle PWA'er

## Motivation
Christian 24/10 2026: «Lav en vejledning som alle apps skal læse for at optimere vores mobile pwa til også at understøtte iPhone Duo samt lignende Samsung eller andre devices med klap skærm.» Med iPhone Duo (Safari 27.1) og Android-foldetelefoner skifter viewport mellem 382–951 CSS px i bredden og 368–902 i højden; en app der kun er testet ved 393×852 kan klippe navigation på den lave ydre skærm.

## Scope
- Den fulde danske standard: `docs/guides/foldables-pwa.md` (ejerens udkast + målte fakta fra webkit.org/blog/18486 + kodeeksempler med feature detection + Lens-testbredder).
- Kortversionen til agenter som Discovery-tip `foldables` på platformen `frontend` (scripts/inventory-data.mjs) — dermed inline i /ai og llms.txt, som hver session læser før den bygger.
- Søgeord (foldable, iphone duo, galaxy fold/flip, viewport segments, device posture) på frontend-platformen.
- Non-goals: at rette de enkelte apps (hver app ejer sin egen PWA; D-5f65b6 — denne standard er ejerens ordre, men selve tilpasningen sker i hvert repo), en @broberg-pakke, en Lens-fold-emulering.

## Arkitektur
Ingen kode. Discovery-data + en guide-fil. Discovery udrulles af inventory-fresh.yml ved push til main.

## Reuse
Discovery er flådens eksisterende kanal for retningslinjer (infra-tips). Ingen ny kanal.

## Åbne spørgsmål
- Skal standarden også ind som kanonisk CLAUDE.md-sektion (cardmem distribuerer dem til alle repoer), så den læses ved hver opstart og ikke kun ved planlægning? Det er cardmems kanal og ejerens valg.
- Chromiums understøttelse af Device Posture / Viewport Segments på Android er ikke målt her — guiden siger «tjek MDN/caniuse».

## Rollout
Commit → push → inventory-fresh udruller Discovery → læs tippet LIVE tilbage.
