# F092.28 — ikon-knap i gruppe-overskriften

scout #2742 (11/10). Ejeren godkendte chat-mockup v8 i dag, som Claude Desktop: ved gruppe-overskriften «Historik» sidder en lille ikon-knap til højre (sliders-ikon, aria-label «Filtrér og sortér», aria-haspopup="menu", aria-expanded), der åbner en menu. Menuen bygger scout selv, placeret ud fra knappen.

## Ændring (app-shell, minor, additiv)
- `NavGroup.action?: { icon; label; expanded?; onClick(anchor: HTMLElement); testid? }`.
- Overskriftsrækken bliver en flex-række: overskriften (knap eller tekst) + action-knappen yderst til højre. Gælder både foldbare grupper og `collapsible: false`. Ikke ved `hideLabel` (der er ingen overskrift).
- Knappen: 28px, ikon --fg-muted, hover/active som `.bas-iconbtn`. aria-label=label, aria-haspopup="menu", aria-expanded=expanded. testid = `testid ?? sidebar-group-<slug>-action`.
- Klik kalder `onClick(knappen)` og folder ikke gruppen (knappen er ikke inde i fold-knappen).
- README + eksempel-appen.

## Ikke her
Menuen selv (den er scouts). En fælles menu-komponent er F092.29.

## Reuse
Bruger skallens ikon-knap-stil (`.bas-iconbtn`).
