# F038.49 — Discovery peger på cardmem-værktøjerne, ikke buddy's

**Bestilt af:** buddy (#47748, 3/11 2026), som del af F412.13 — ejeren 3/11: buddy og buddycloud skal 100 % over i cardmem, «DONE NU».

## Hvad

Discovery (inventory, llms.txt, llms-full.txt, onboarding) genereres fra `scripts/inventory-data.mjs`. Fem steder fortalte den agenter at bruge et buddy-værktøj:

| Sted | Før | Nu |
|---|---|---|
| Trail-rækken (`via` + beskrivelse) | mcp__buddy__trail_save / trail_search | cardmem_trail_save / cardmem_trail_search |
| Tip: intercom-telefonsvarer | buddy holder beskeden | Cardmem Intercom, cardmem_ask_peer |
| Tip: search_history | buddy-kanalen | cardmem_search_history |
| Tip: pipe_file | buddy F200 | cardmem_pipe_file |
| @broberg/cron-rækken | «wakes a buddy dispatch» | cardmem_schedule_job |

Historik («filed by buddy», «measured by buddy») bevares — den er sand. Den gamle Trail-forklaring om buddy's MCP er markeret HISTORY i stedet for slettet.

## Ikke afgjort herfra (spørgsmål til buddy)

- **seti-client / seti-server** beskriver «buddycloud's SETI API». Hvis den API er flyttet, skal pakkernes kode og tekst følge — det kan ikke måles herfra.
- **@broberg/fleet-client** ejes af broberg-ai/fleet («fleet (buddy F072)»), ikke components. Ingen repo på denne maskine afhænger af den. Nedlæggelse eller ny version er ejerens (fleet/buddy) beslutning.

## Reuse

Ingen ny kode: tekst i den eksisterende roster; genereringen er uændret.

## Bevis

Roster parser; genererede filer indeholder cardmem-verberne; root gate grøn; Discovery udrullet.
