# F105.3 — detail.node_version fra det udrullede image

## Hvorfor
Ejeren har bestilt Node 24 LTS i alle containere. cardmem (F401.6) vil have natjobbet til at måle det på det image der FAKTISK udrulles — ikke på en Dockerfile, der kan sige én ting mens basis-imaget leverer en anden. cardmem gemmer feltet, og auditten markerer Fly-apps der ikke kører v24.

## Scope
- I trinnet efter `docker pull "$IMAGE"` (digest-pinnet, F105.1): `docker run --rm --entrypoint node "$IMAGE" -v`.
- Output matcher `^v\d+\.\d+\.\d+$` → sendes som `detail.node_version`; ellers `null` (image uden node, fx Bun).
- Målingen må aldrig fejle kørslen eller påvirke scan/udrulning.
- Udgives som engine-tag `v1.0.2`.

### Non-goals
- At håndhæve v24 i motoren (det er cardmems audit).
- Bun-version.

## Reuse
Udvider den eksisterende motor (F105.1); ingen ny pakke.

## Rollout
Tag v1.0.2 → cardmem peger pilot på v1.0.2 → målt i loggen.
