# F092.11 — Sprog-række i brugermenuen

**Kilde:** Christian via appkit #1749 (appkit-F008.3), med skærmbillede af en «Language»-række med segmenteret EN | DA: «Sprogvælger skal bruge denne. På dansk skal der jo bare stå Sprog og engelsk Language. Kommer der flere sprog til finder vi et andet sted at styre det.»

## Design
- `UserMenuProps.language?: { value: string; options: { id: string; label: string }[]; onChange(id): void }`.
- Samme segmenterede kontrol som Tema/Palet/Flader/Baggrund (genbrug af den eksisterende segment-komponent i UserMenu), etiket fra TEXT (`language`: «Sprog»/«Language»).
- Appen ejer sproget (i18n, URL, cookie); skallen viser og melder valget. Ingen persistens i skallen.
- Kun få sprog (to i dag). Flere sprog → et andet sted (Christians ord), ikke en dropdown her.
- Tastatur: pile mellem valg, Enter/Space vælger; aria-pressed.

## Reuse
Genbruger UserMenu's eksisterende segment-række. Ingen ny afhængighed.
