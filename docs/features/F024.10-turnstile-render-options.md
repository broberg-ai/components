# F024.10 — useTurnstile render options (appearance, theme, size, language)

## Why
jam, 22 Oct 2026 (intercom 3933): Christian finds the dark Turnstile box («Succes! CLOUDFLARE») in the Jambalaya sign-up ugly and wants it low-key. Cloudflare supports `appearance: "interaction-only"` (box shown only when a click is needed), `theme`, `size` and `language` as render options, but `useTurnstile(siteKey)` passes none of them.

## Scope
- `useTurnstile(siteKey, options?)` in the shared core (React + Preact entries). `TurnstileRenderOptions = { appearance?: "always" | "execute" | "interaction-only"; theme?: "light" | "dark" | "auto"; size?: "normal" | "flexible" | "compact"; language?: string }`.
- Options are spread into `turnstile.render` BEFORE the hook's own `sitekey` and callbacks, so they can never replace them.
- Options are read when the widget is rendered (on mount / siteKey change), not on every render — an inline object literal must not re-render the widget each time.
- Without options: identical render call to 0.3.0.

### Non-goals
- Exposing callbacks or `execution` mode.

## Reuse
This is the shared package `@broberg/forms-turnstile`.
