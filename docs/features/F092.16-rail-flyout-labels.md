# F092.16 — Railens flyout viser ingen undermenu-punkter

**Rapporteret af:** appkit 10/10 2026 (#2475), målt med Lens run 3aca21d1 / screenshot ee47326d step 8.

## Fejlen
I rail-tilstand (foldet sidebar, collapse="icon", eller telefonens rail) åbner et punkt med børn en flyout (F092.6). Flyouten viser sin titel, men børnene er usynlige: `.bas-sidebar.is-railed .bas-item__label { display:none }` (specificitet 0,3,0) slår `.bas-flyout .bas-item__label { display:block }` (0,2,0), fordi flyouten renderes INDE i `.bas-sidebar`. De øvrige rail-regler (`.bas-item` centreret med padding 8px 0, tælleren absolut placeret) rammer også flyoutens punkter.

## Løsning
Modregler scoped til `.bas-sidebar.is-railed .bas-flyout …` (0,4,0) der gendanner etiket, venstrestilling, padding og tæller for flyoutens punkter. Ingen ændring i markup.

## Bevis
- vitest: app-shell.css indlæst i happy-dom, rail + åben flyout, assert computed display og layout på børnene. Mutationskontrol.
- Lens i rigtig browser (examples/app-shell, 1440) med elementFromPoint på et barn.
