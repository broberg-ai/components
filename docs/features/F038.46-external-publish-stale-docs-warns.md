# F038.46 — Forældede sider pga. en ekstern udgivelse advarer, de stopper ikke

**Bestilt af:** Christian 26/10 2026, «ja til alle tre» (spørgsmålet om docs-tjekket der ogsa blev rødt ved eksterne udgivelser).

## Motivation
F038.45 klarede roster-tjekket. Men Discovery-siden viser hver pakkes nyeste npm-version og udgivelsestid, hentet live. Når lens, auth-relay eller ai-sdk udgiver, ændrer de genererede sider sig, og trinnet «Fail if the committed docs are stale» stopper udrulningen — 5 gange på et døgn.

## Rettelse
- `scripts/npm-latest.mjs`: med `DISCOVERY_FREEZE_EXTERNAL=<fil>` læses pakker der IKKE bor i `packages/` fra filen (den committede npm-meta.json) i stedet for registry.
- Nyt `scripts/check-docs-stale.mjs` (kaldt fra workflowet): diff de fire sider. Ingen forskel → ok. Forskel → genbyg med eksterne låst; ingen forskel nu → `::warning::` der navngiver de eksterne pakker der flyttede sig, exit 0. Stadig forskel → `::error::` som i dag, exit 1.

## Non-goals
- At ændre hvad siden viser.
- At ændre live-fresh eller udrulningen.

## Reuse
Samme «egen pakke»-regel som F038.45 (check-roster-versions.mjs). Stub-registry-mønstret fra test-roster-catch-up.mjs.

## Rollout
Én commit: script + test + workflow-linje.
