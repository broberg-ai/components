# F110.16 — Vilkårene lover analyse, også hvor den ikke sker

> **Udløser:** jam #47360, 1/11 2026: terms (da), afsnit «Dit indhold», siger altid «… herunder pseudonymiseret analyse for at forbedre vores produkter», også når produktets facts.conversationAnalysis = false (Jam). Privatlivspolitikken håndterer det korrekt via facts-blokken. Fejl i components' tekst → bestilt arbejde (D-bbeebd).

## Rettelse
Fjern løftet fra vilkårene: sætningen ender med «og som beskrevet i privatlivspolitikken.» Privatlivspolitikken siger, pr. produkt, om analyse finder sted. Ét sted for den oplysning, ikke to.

## Konsekvens
terms-teksten og dens hash ændres (stadig UDKAST). Release-rapport siger det, så en accept registreret på den gamle hash kan genkendes.

## Ikke i scope
At gøre terms-tekst betinget af fakta (holder vilkårene ens for alle; produktforskelle bor i privatlivspolitikken).
