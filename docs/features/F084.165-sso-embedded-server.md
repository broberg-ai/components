# F084.165 — @broberg/sso: indlejret login og kontooprettelse fra serveren

## Open questions (blokerer kode)
- **Web-klient-kontrakten er ikke publiceret af BID.** jam (#3416) relæer: /embedded/* kaldes fra serveren med `Authorization: Basic client_id:client_secret` (ellers 401 invalid_client) og `end_user_ip` i kroppen; `start` tager `nonce` (står i id_token); `GET /embedded/terms?lang=da|en` → `{version,text,links:[{label,url}]}`; ved `intent:"signup"` SKAL `start` have `terms_version` = den gældende, ellers `400 terms_outdated`. broberg-id-F084.166 doc er uændret siden f9e148d (kun udvidelses-klienten), F084.167 har ingen kontrakt-sektion. Kode skrives mod BID's skrevne kontrakt, ikke mod et relæ.
- Hvilken form har `client_secret`-klienten i BID's register (samme som completeLogin bruger i dag?).

## Motivation
Ejeren har godkendt (via jam 15/10) at Jams web-app får login og kontooprettelse i eget design via BID's indlejrede API. Uden en fælles serverdel ruller hver app sin egen auth-kode — imod reuse-reglen og D-4d0783 (sso er den eneste dør).

## Design
- `createEmbedded(config)` i `@broberg/sso` (server): bruger samme `config` (issuer, clientId, clientSecret, redirectUri, cookie-nøgle) som de eksisterende flows.
- `start({ email, intent, name?, termsVersion?, endUserIp })` → laver PKCE-verifier + nonce, kalder `/embedded/start` med Basic-auth, returnerer `{ expiresIn }` + en `Set-Cookie` for en signeret, httpOnly, kortlivet flow-cookie med `{ flowId, verifier, nonce }` (samme signering som completeLogin's transaktions-cookie).
- `verify(cookie, code)` / `sendSms(cookie)` / `verifySecondFactor(cookie, method, code)` → `{ next: "second_factor", methods }` eller → bytter koden på `/oauth2/token` med `client_secret` + verifier → verificerer id_token (signatur via eksisterende JWKS, iss, aud, **nonce**) → returnerer samme `{ claims, idToken, … }` som `completeLogin`.
- `terms(lang)` → BID's tekst ordret (appen SKAL vise den).
- Fejl som data efter kontraktens tabel + `terms_outdated`.

## Non-goals
- Appens sider/UI (Jam's F001.20).
- Adgangskode.

## Reuse
Udvider `@broberg/sso` (JWKS, cookie-signering, completeLogin-claims genbruges). Klientsiden for udvidelser findes allerede i `@broberg/web-clipper/auth` (F099.24).

## Rollout
Minor-udgivelse; release-rapport til broberg-id og alle sso-forbrugere (D-4d0783). Ikke breaking.
