# F110.21 — legal: the subprocessor table overflows a 393 px phone

Parent: F110 (@broberg/legal). Reported by mailworker (intercom #52841) while measuring F110.18 live with Lens at 393 px: the subprocessor table is 419 px wide, its cells do not wrap, the page scrolls sideways. Mailworker patched its own CSS; every other consumer of renderHtml has the same defect.

## Why it is ours
The table comes from the package's own HTML renderer. A consumer must be able to style the document without having to repair it (D-55a2af: no sideways scrolling on a phone, verified at 393 px with the Lens critic).

## Plan
1. Reproduce at 393 px with Lens; record the measured width.
2. Let table cells wrap (and long tokens such as hostnames break) inside the package's rendering — no consumer CSS needed.
3. A structure test that fails without the rule, plus a mutation; the text contentHash must not change.
4. Release with a report to all consumers: the rendered output moved (D-b7eb14).
