# F092.34 — Sidebar user menu: «Log ud» never scrolls out of view; focus ring only for keyboard

scout #2855 (11/10), owner-reported with a screenshot: «Ikke engang Sign out kan være i fokus og vises 100% efter jeg lige har trykket på menuen i bottom left». Scout measured (Lens 4be5b998, 1440×900): `.bas-menu.is-up` is 615px tall with `max-height` = space above the button and `overflow-y: auto`; on Christian's lower screen it scrolls and «Log ud» sits half under the edge.

## Fix
1. In the sidebar placement (`.bas-menu.is-up`, the one that scrolls) the head (`.bas-menu__who`) is `position: sticky; top: 0` and the sign-out block is wrapped in `.bas-menu__foot` with `position: sticky; bottom: 0`, both on the card background — only the middle scrolls. The topbar dropdown does not scroll and is unchanged.
2. The trigger `.bas-userbtn`: `:focus:not(:focus-visible) { outline: none }` (wins over an app's global `button:focus` rule by specificity) and `:focus-visible` draws the accent ring. Same principle as ItemActionsMenu in 0.22.0.

Non-goals: menu content, positioning.

This is the shared package itself (@broberg/app-shell).
